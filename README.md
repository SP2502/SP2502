## 🧠 What I'm Building

### 🔬 Cortex — Open Deep Research

An open-source deep research system I'm currently building.

The goal is not just to make a chatbot that searches the web. Cortex is being designed as a system that can:

- Understand a research question
- Break complex questions into smaller tasks
- Plan a research process
- Search and collect information
- Compare information from different sources
- Reason over collected evidence
- Handle long research workflows
- Produce structured research results
- Work with different AI models and tools

I'm treating Cortex as a serious engineering project rather than a single AI prompt.

**Status:** 🚧 Active development

---

### 🔌 Universal API — Flagship Project

My long-term flagship project.

The idea is to make working with different APIs and services much simpler by creating a **universal layer between applications and APIs**.

Instead of every application having to deal with completely different APIs, authentication methods, formats, and integrations, Universal API aims to provide a consistent way to work with them.

This is one of my biggest projects because it combines several things I want to understand deeply:

- APIs
- Authentication
- Integrations
- Developer tooling
- Automation
- AI agents
- Infrastructure
- Software architecture

This project is still being designed and built. I expect the architecture to change a lot as I learn more.

**Status:** 🧪 Early development / flagship project

### ⛏️ Minecraft Bot

One of my earlier serious automation projects.

What started as a Minecraft bot became a way for me to learn how software can interact with an environment, make decisions, and perform actions automatically.

The project has helped me explore:

## 🧭 The Direction I'm Going

These projects may look unrelated at first.

They aren't.

I'm interested in the space where **software can understand something, make decisions, and then actually do something with that understanding.**

That is why my projects have gradually moved from:

**Minecraft automation → software utilities → AI systems → research agents → developer infrastructure**

I'm especially interested in what happens when AI is combined with normal software engineering instead of being treated as just a chatbot.
